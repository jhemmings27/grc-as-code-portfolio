What this is

From written policy to running pipeline

Most GRC work lives in documents someone checks quarterly. This project takes controls that already exist as policy — MFA requirements, encryption standards, access review cadence — and expresses them as code that runs on every commit, catching violations before they ever reach production.

Built as a hands-on extension of a broader GRC portfolio: a risk register, a HIPAA / SOC 2 / PCI-DSS compliance mapping, and a NIST CSF / ISO 27001 gap analysis for the same hypothetical company.

Toolchain

Four layers, one pipeline

Open Policy Agent
Policy as code, written in Rego — evaluates account data against a written MFA rule.
Checkov + Terraform
Scans infrastructure-as-code for misconfigurations before anything is deployed.
GitHub Actions
Runs the scan automatically on every push and pull request against main.
Custom Rego policy
A Meridian-specific rule for PHI-tagged storage — and its documented limits.
